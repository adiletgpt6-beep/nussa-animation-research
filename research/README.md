# Nussa — анализ топ-15 эпизодов

Исследование для оригинального русскоязычного сериала. Методика и ограничения:

- Источники: только метаданные YouTube (yt-dlp), оригинальные автосубтитры (id), раскадровки (storyboards) и превью.
- Видео и звук НЕ загружались (YouTube требует подтверждение «не бот»; обход не выполнялся).
- Медиа и полные субтитры хранятся только во временной папке и в репозиторий не попадают. В репозитории — лишь короткие цитаты (≤ 2 предложений).
- Ничего не выдумывается: что не удалось увидеть/услышать, помечено «не проанализировано».

Структура:
- `catalog.csv` — каталог всех вкладок канала.
- `data/top15_selection_log.csv` — кандидаты и причины включения/исключения.
- `top15.csv` — итоговый список NS-001..NS-015.
- `episodes/NS-0XX.md` — анализ эпизода; `data/episodes/NS-0XX.json` — измеренные числа.
