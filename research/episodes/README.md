# Карточки серий NS-001 … NS-015

Идентификаторы NS-001 … NS-015 присваиваются **по рангу просмотров** после сбора каталога
(`research/pipeline/select_top15.py` → `research/top15.csv`). Пока каталог не собран
(см. `research/FINAL_REPORT.md`, раздел «Блокеры»), карточек нет. Пустые карточки с выдуманными
названиями создавать нельзя.

Карточка создаётся по шаблону `_TEMPLATE.md` и заполняется так:

1. **Числовые поля** берутся из `research/data/episodes/NS-xxx.metrics.json`, без ручного ввода.
2. **Сценарный, актёрский и религиозный разбор** пишется по расшифрованному транскрипту и контактным листам.
   - Расшифрованные материалы лежат только локально, вне репозитория.
   - В карточку попадают короткие цитаты (не более 1–2 предложений), а не полный текст.
3. **Блок «Проверка полноты»** заполняется по полям `status` из metrics.json. Если данных нет, так и пишется.
