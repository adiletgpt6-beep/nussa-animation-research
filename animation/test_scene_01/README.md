Дата: 2026-11-25. Статус: **технический тест конвейера**.

- Герои **временные** и не утверждены.
- Сцена **не публикуется** как часть сериала.

## Что это

Два ролика по **19,3 с** с одинаковыми сценой, персонажами, действиями, озвучкой и звуком:

| Вариант | Как сделан |
|---|---|
| `test_scene_01_2d.mp4` | Стиль «2D-вид из 3D» (S2 в `production/series/ART_STYLES.md`). Blender Workbench: двухтоновая заливка (toon), чернильный контур (постобработка OpenCV), фактура бумаги, контактные тени-пятна |
| `test_scene_01_3d.mp4` | Стилизованное 3D (S3). Blender EEVEE: мягкие площадные источники, солнце из окна, тени, AgX |

**Параметры:** 1920×1080, 16:9, 30 fps (CFR), H.264 + AAC 48 кГц, русская речь, **без музыки**.

Ссылки на просмотр и скачивание — в PR и отчёте сессии. Видео в git не хранятся: R2 из этой сессии недоступен, см. «Ограничения».

## Как устроено

| Слой | Реализация | Файл |
|---|---|---|
| Голоса | **Piper TTS** (бесплатно, локально), голос `ru_RU-irina-medium`; тайминги фонем из модели. Мальчик — тот же голос выше (+5 полутонов), бабушка — ниже (−2) с лёгким дрожанием | `src/voice.py`, `config/dialogue.json` |
| Персонажи | Процедурные: скелет 60+ костей (тело, 3 пальца + большой на каждой руке, глаза, веки, брови, хохолок); тело — Skin-модификатор; веса — по расстоянию до костей; лицо — глаза (белок, радужка, зрачок, блик), веки с ресницами, брови, нос, щёки, рот (губы, полость, зубы, язык) с формами-ключами | `src/blender/character.py`, `specs.py` |
| Окружение | Площадка подъезда: плитка, крашеные стены, лифт с объявлением, дверь, окно, батарея, цветок, перила; сумки, мяч, продукты | `src/blender/environment.py` |
| Походка | Фазовый генератор шагов: бег (полётная фаза), торможение, ходьба, «досадочные» шаги при развороте. Стопы стоят на месте (IK), пятка-носок | `src/blender/animation.py` (`gait`) |
| Тело | Таз (покачивание, вертикаль, присед), позвоночник (наклон, скрутка, крен), дыхание, руки FK и IK с переключением, пальцы | `animation.py` (`bake_actor`) |
| Голова и глаза | Автоповорот головы за взглядом с задержкой — **глаза опережают голову**. Саккады 0,1 с + микросаккады. Моргания: случайные 2–5 с + принудительные на поворотах головы (как в VID-001) | `animation.py`, `build.py` |
| Мимика | Брови (подъём, «домик», асимметрия), веки (широко, прищур, нижнее веко в улыбке), улыбка или огорчение, кивки и вскидывание бровей на ударных слогах | `build.py` (каналы) |
| Lip sync | Фонемы Piper → 14 визем русской речи → формы рта, зубы, язык, челюсть. Опережение 1 кадр, коартикуляция. **Губы обязательно смыкаются на «м/б/п»** | `animation.py` (`viseme_track`) |
| Предметы | Мяч под рукой → бросок → отскоки, качение, вращение (простая физика). Сумка: хват → подъём → висит на руке с маятником | `build.py` |
| Камеры | 7 планов: общий с панорамой, «восьмёрка» через плечо, боковой, выход | `build.py` |
| Звук | Процедурные SFX: шаги по плитке (бег, ходьба, шарканье), скрип подошв, отскоки и качение мяча, шорох сумки, глухой стук содержимого, писк часов, вздох, тяжёлое дыхание, похлопывания, лязг лифта, фон подъезда и улицы, птицы. Эхо подъезда. Приглушение шумов под речью. **Музыки нет** | `src/sfx_mix.py` |
| Мастер | FFmpeg: H.264 CRF 17, AAC 192k, loudnorm −15 LUFS / −1,5 dBTP | `src/assemble.sh` |
| QC | Формат, длительность, громкость, классификатор музыки (AudioSet AST), замёрзшие и чёрные кадры, смыкание губ на «м/б/п», моргания, скольжение стоп, разборчивость речи (faster-whisper → WER) | `src/qc.py` → `qc/*.json` |

Полный цикл — `make_all.sh`. Сцена пересобирается за секунды. Рендер без видеокарты: EEVEE через программный OpenGL. Время:
- 3D — ≈ 13 с/кадр;
- 2D — ≈ 3,5 с/кадр.
