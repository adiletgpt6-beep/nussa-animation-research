# Постоянные главные герои: семья Самира и Ясмины

Сериал строится вокруг одной мусульманской семьи. Внешность, возраст, характеры, голоса и пластика героев **постоянны**. Менять их можно только по указанию заказчика.

Рабочее название сериала — «Самир и Ясмина». Название не утверждено заказчиком.

**Где задан дизайн:**
- `characters/samir.py`, `characters/yasmina.py`, `characters/leyla.py` — силуэт, одежда, цвета, пропорции;
- `characters/family_parts.py` — хиджаб, платочек с косичками, волосы, вид со спины;
- `engine/face.py` — глаза, брови и 17 форм рта;
- `engine/character.py` — скелет и кисти.

**Листы героев** (`library/art/sheet_*.png`) содержат повороты (анфас, 3/4, профиль, вид со спины), 8 эмоций и 14 форм рта. Общий портрет — `library/art/family_lineup.png`.

**Голоса** закреплены в `library/voices/voices.json`. Подбор описан в `library/voices/casting.json`.

> Ограничение движка: полный профиль (поворот головы ≥ 0.8) выглядит хуже 3/4. В постановке поворот головы держится в пределах ±0.6.

## Самир, 9 лет — старший брат

| | |
|---|---|
| Внешность | Растрёпанные каштановые волосы с вихром, веснушки, большие карие глаза. Бирюзово-голубой свитшот с жёлтой нашивкой-самолётиком, белый ворот футболки, тёмно-синие брюки, оранжевые кеды |
| Характер | Добрый, заботливый, любознательный, иногда озорной |
| Сильные стороны | Помогает сестре, придумывает планы (расписание полива), много знает из книг |
| Слабые стороны | Иногда торопится с выводами и сам попадает в смешные ситуации (сажает печенье) |
| Привычки | Всегда носит лупу и всё «исследует»; рисует схемы и расписания |
| Манера речи | Живая, «по-научному»: «В книге написано…», затем смешной вывод |
| Жесты | Разводит руками, указывает пальцем, присаживается на корточки рядом с сестрой |
| Пластика | Энергичная: быстрые шаги, заметный размах рук; подпрыгивает от испуга со сжатием и растяжением (стиль: noise 1.0, bob 1.1) |
| Голос | ElevenLabs «Viktoriia — Energetic and Inviting» (`8M81RK3MD7u4DOJpu2G5`), eleven_v3, stability 0.5. Взрослая исполнительница с мальчишеским тембром, F0 ≈ 218 Гц |

## Ясмина (Ясми), 5–6 лет — младшая сестра

| | |
|---|---|
| Внешность | Круглое личико, очень большие карие глаза, чёлка и две косички с мятными бантиками. Солнечно-жёлтый платочек в белый горошек, завязанный сзади. Персиковое платье с белым воротничком и кармашком-цветком, сиреневые легинсы, мятные кеды |
| Характер | Милая, весёлая, искренняя, очень эмоциональная, задаёт много вопросов |
| Сильные стороны | Доброе сердце; находчивость — удивляет брата («Возьми мою ленточку!») |
| Слабые стороны | Нетерпение: сначала делает, потом думает |
| Привычки | Разговаривает с растениями и животными; подпирает щёки кулачками, когда ждёт |
| Манера речи | Звонкая, восклицательная, простые слова, уменьшительные («подсолнушек»), вопросы («А за две?») |
| Жесты | Подпрыгивает от радости, прижимает ладошки к щекам, машет руками |
| Пластика | Самая подвижная: сильнее подпрыгивает при ходьбе, живые повороты головы, частые кивки (стиль: noise 1.3, bob 1.4) |
| Голос | ElevenLabs «Nataly — Youthful, Gentle and Cute» (`NhY0kyTmsKuEpHvDMngm`), eleven_v3, stability 0.5. F0 ≈ 298 Гц, самый широкий диапазон интонации среди кандидатов |

## Мама Лейла, около 30 лет

| | |
|---|---|
| Внешность | Молодая, мягкие черты, миндалевидные карие глаза. Пудрово-розовый хиджаб обрамляет лицо и мягко спадает на плечи. Длинное платье цвета шалфея, светлый кремовый кардиган, тёплые коричневые туфли |

| Манера речи | Неторопливая, тёплая, разговорная, не официальная |
| Жесты | Подзывает ладонью, обнимает, гладит по голове |
| Пластика | Плавная: короткие спокойные шаги, малая амплитуда головы и рук, мягкие кивки (стиль: noise 0.55, bob 0.55) |
| Голос | ElevenLabs «Kari — Friendly, Warm and Engaging» (`Jbte7ht1CqapnZvc4KpK`), eleven_v3, stability 0.5. Русскоязычный голос из Казахстана, F0 ≈ 167 Гц, неспешный темп |

## Второстепенные

**Ёжик Колючкин** — садовый гость без голоса, только звуки: сопение, фырканье. Нюхает всё подряд и сворачивается в клубок (`characters/hedgehog.py`).

**Голубь** — гость сада (`backgrounds/props.py`).

В будущих сериях можно добавить папу, бабушку, дедушку, соседей, друзей и домашнего питомца, но основой остаются брат, сестра и мама. Порядок добавления:
1. Дизайн по образцу `characters/samir.py`.
2. Голос: сначала кастинг минимум 3 кандидатов через кэш `engine/voice.py`.
3. Лист героя — `tools/make_family_art.py`.
