# «Сад на крыше» — производство 2D-мультсериала

Оригинальный мусульманский 2D-мультсериал для детей 4–12 лет, русская озвучка, YouTube.

**Серия 1:** «Семечко, которое не спешило» — 4:23, 1920×1080, 30 fps, H.264 + AAC, без фоновой музыки.

| Что | Где |
|---|---|
| Сценарий (реплики + теги эмоций) | `episodes/ep01/script.py` |
| Постановка: камеры, действия, эмоции, реквизит, звуковые события | `episodes/ep01/episode.py` |
| Звук: голоса, шаги из походки, эффекты, атмосферы, без музыки | `episodes/ep01/mix.py`, `engine/sfx.py` |
| Озвучка ElevenLabs: генерация с кэшем, журнал расходов | `engine/voice.py`, `episodes/ep01/make_voices.py`, `episodes/ep01/voice_meta/` |
| Рендер | `episodes/ep01/render_ep.py`, `engine/render.py` |
| Проверка готовой серии | `tools/qc_episode.py` → `episodes/ep01/QC_REPORT.md` |
| Для устаза | `episodes/ep01/USTAZ_REVIEW.md` |
| YouTube: название, описание, обложка | `episodes/ep01/YOUTUBE.md`, `library/art/thumbnail_1280x720.png` |
| **Библиотека героев, голосов, мимики, форм рта** | `library/CHARACTERS.md`, `library/voices/`, `library/art/` |

## Технология (почему так)

**Настоящая рисованная 2D-векторная анимация:** Python + Skia, кривые Безье, сглаживание, мягкие тени, градиенты, фактура бумаги.

- **3D не используется.** Плоских шейдеров тоже нет.
- **Не статичные картинки.** Каждый кадр перерисовывается из скелета персонажа.
- **Не готовые SVG-фигуры.** Конечности строятся из «трубок» по кривой и гнутся плавно.

| Слой | Реализация |
|---|---|
| Персонаж | Скелет с FK/IK: тело, руки, ноги, кисти с 3 пальцами и большим; голова с поворотом (yaw): черты лица смещаются по сфере, щека — в сторону взгляда; волосы и платки — передний и задний слои |
| Лицо | Глаза: белок, радужка с градиентом, зрачок, 2 блика, тень века, веки для моргания и прищура, ресницы. Брови: подъём, «домик», асимметрия. Нос, румянец. Рот: 17 форм (14 фонемных + улыбка, ах, плач) с интерполяцией; зубы и язык внутри |
| Движение | Ключи с easing (slow in/out, overshoot); генератор шагов (ходьба, бег) с постановкой стоп; дыхание; squash & stretch; пружины вторичного движения (платок, хохолок, подол); моргания (случайные + на поворотах); кивки на ударных гласных; «живой» шум головы |
| Lip sync | Тайминги символов ElevenLabs → русские буквы → виземы; коартикуляция; гарантированное смыкание губ на м/б/п. Проверено покадрово |
| Окружение | Рисованный фон «Сад на крыше» в 5 освещениях: утро, день, вечер, гроза, после дождя. Слои: небо, облака, город в воздушной перспективе, мечеть, соседняя крыша, парапет, грядки, шпалера, гирлянда, бочка, шланг, будка с открывающейся дверью, скамейка, лужи |
| Эффекты | Вода (струя, брызги, перелив), дождь, листья на ветру, молния со вспышкой, искорки, слёзы, голубь, ёжик |
| Звук | Процедурные эффекты (`engine/sfx.py`): шаги по касанию стопы, вода, дверь, земля, голубь, гроза, атмосферы. Голоса — с лёгким отзвуком; фон приглушается под речью |

**Рендер:** ≈ 0,2 с на кадр на 4 ядрах CPU, без GPU; серия целиком — около 27 минут.

## Почему не стиль прошлого теста (`animation/test_scene_01`)

Тестовый ролик был отклонён заказчиком. Недостатки:
1. **3D-модели с плоским шейдером** вместо 2D: «игрушечные» формы, шарообразные головы, обувь-капли, причёска-шапочка.
2. **Нет дизайна героев:** пропорции и черты лица построены из примитивов, нет выразительных глаз и аккуратных контуров.
3. **Окружение-коробка:** голые стены и пол, мало деталей, нет глубины и атмосферы.
4. **Синтетический голос Piper:** один голос на двоих, ровная интонация.
5. **Ограниченная мимика:** рот — плоская полоска, брови — «точки», веки «сонные».
6. **Ролик на 19 секунд,** а не история.

Что сделано иначе в серии 1:
- новые герои с листами персонажей;
- лица, нарисованные кривыми;
- 2D-освещение: мягкие тени, контровой свет, цветокоррекция по времени суток;
- детальный фон;
- профессиональные голоса ElevenLabs v3 с эмоциональными тегами;
- полноценная история на 4:23.

## Масштабирование на следующие серии

1. Скопировать `episodes/ep01` → `episodes/ep02`.
2. Написать `script.py`: реплики с тегами эмоций.
3. `make_voices.py` — голоса берутся из `library/voices/voices.json` и не меняются.
4. В `episode.py` — постановка: функции сцен с ключами `A.k(t, ...)`, `E.line(id, t)`, `E.cut(...)`, `E.sfx_at(...)`.
5. Повторно используются:
   - герои, скелеты, кисти, мимика, рты, походки;
   - фон и его освещения;
   - реквизит и библиотека звуков.

   Новая локация — новый модуль в `backgrounds/`.
6. `render_ep.py` → `mix.py` → сведение FFmpeg → `tools/qc_episode.py`.

## Запуск

```bash
pip install skia-python numpy scipy soundfile opencv-python-headless   # Python 3.13
export ELEVENLABS_API_KEY=...   # только для новых реплик; готовые берутся из кэша
python episodes/ep01/make_voices.py VOICE_DIR
python episodes/ep01/render_ep.py VOICE_DIR video.mp4
python episodes/ep01/mix.py VOICE_DIR mix.wav
# сведение с громкостью -14 LUFS: см. QC_REPORT.md
```
