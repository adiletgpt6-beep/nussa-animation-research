# Мультсериал о семье Самира и Ясмины — производство 2D

Оригинальный мусульманский семейный 2D-мультсериал для детей 4–12 лет: русская озвучка, YouTube. Рабочее название — «Самир и Ясмина», заказчиком не утверждено.

**Серия 1, версия 2:** «Семечко, которое не спешило». Формат: 1920×1080, 30 fps, H.264 + AAC, без фоновой музыки.

Первая версия серии («Сад на крыше», герои Алсу, Айдар и бабушка) сохранена для сравнения в `episodes/ep01_v1_roof/`.

## Технология

Вся анимация рисуется кодом: Python + Skia, векторная 2D-графика. Каждый кадр перерисовывается из скелета персонажа. 3D, плоских шейдеров и AI-генерации видео нет.

| Слой | Реализация |
|---|---|
| **Герои** | Скелет с FK/IK, конечности — гнущиеся «трубки» по кривой, кисти с пальцами. Голова поворачивается (yaw), есть вид со спины. Хиджаб с открытым овалом лица и мягкой тенью ткани; платочек с косичками; растрёпанные волосы с вихром |
| **Лицо** | Глаза с градиентной радужкой и двумя бликами, веки, ресницы, брови, румянец. 17 форм рта (14 фонемных и 3 эмоциональные) |
| **Движение** | Ключи с easing, генератор шагов, дыхание, сжатие и растяжение, пружины для ткани и волос, моргания. У каждого героя свой стиль пластики. Слушатели автоматически смотрят на говорящего и кивают |
| **Lip sync** | Тайминги символов ElevenLabs переводятся в виземы русских букв, с коартикуляцией; губы смыкаются на М/Б/П |
| **Окружение** | 4 локации, 6 пресетов света, параллакс до 4 слоёв, мягкий свет из окон. В крупных планах фон размывается (глубина резкости). Свет локации подкрашивает героев |
| **Камера** | Планы: общий, средний, крупный, через плечо, со спины, вставки. Автокадрирование по головам героев. Переходы во времени — мягкое высветление |
| **Звук** | Процедурные эффекты: шаги по касанию стопы (пол или трава), вода, капли, двери, бумага, магнит, ветерок, дождик, птицы. Атмосферы зависят от локации; под речью фон приглушается |

Рендер идёт на CPU без GPU: примерно 0,3 с на кадр 1920×1080, серия целиком — около 45 минут.

## Следующая серия

1. Скопировать `episodes/ep01` в `episodes/ep02`.
2. В `script.py` записать реплики с тегами эмоций. Затем запустить `make_voices.py`: голоса берутся из `voices.json`.
3. Проверить реплики распознаванием (ударения), неудачные перегенерировать.
4. В `episode.py` поставить сцены. Доступные инструменты:
   - `E.loc` — локация;
   - `E.line` — реплика;
   - `E.walk` — ходьба;
   - `E.cut` / `E.move` — камера;
   - `E.insert` — вставка крупным планом;
   - `E.dip` — переход во времени;
   - `E.sfx_at` — звуковое событие.
5. Сделать контактный лист (`tools/contact_sheet.py`) и тестовый фрагмент, затем запустить полный рендер, `mix.py`, сведение и `tools/qc_episode.py`.

## Запуск

```bash
pip install skia-python numpy scipy soundfile opencv-python-headless   # Python 3.13
export ELEVENLABS_API_KEY=...       # только для новых реплик
python episodes/ep01/make_voices.py VOICE_DIR
python tools/contact_sheet.py episodes/ep01 VOICE_DIR /tmp/cs 2.0
python episodes/ep01/render_ep.py VOICE_DIR video.mp4
python episodes/ep01/mix.py VOICE_DIR mix.wav
# сведение -14 LUFS — см. episodes/ep01/QC_REPORT.md
python tools/make_family_art.py library/art   # листы героев, обложка, превью локаций
```
