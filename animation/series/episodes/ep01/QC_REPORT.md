### Дополнительная метрика «малое движение»

Средняя разница по всему кадру < 0,15. Найдено 15 «тихих» отрезков длиной 1,5–6,2 с. Как я их разобрал:

- **Самый длинный, 123–129 с** — вставка «корешок в разрезе земли». Корешок медленно растёт, камера наезжает. Склейка проверена: кадр отличается от прежнего рендера.
- **Остальные** — крупные и средние планы с репликами: двигаются губы, глаза и голова, фон стоит.

Метрика «статичный кадр» по блокам подтверждает, что в этих отрезках движение есть. Тем не менее это тихие места: если на просмотре они покажутся затянутыми, их можно сократить.

## 6. Сведение (воспроизвести)

```bash
python episodes/ep01/render_ep.py VOICE_DIR video.mp4
python episodes/ep01/mix.py VOICE_DIR mix.wav
ffmpeg -i mix.wav -af "loudnorm=I=-14.3:TP=-2:LRA=11,alimiter=limit=0.79:level=false" -ar 48000 mix_norm.wav
ffmpeg -i video.mp4 -i mix_norm.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart ep01.mp4
python tools/qc_episode.py ep01.mp4 episodes/ep01/script.py episodes/ep01/qc_ep01.json
```
