## 2. Что проверено вручную (фактически)

- **Контактные листы.** Кадр каждые 2 с по всей серии. По ним найдены и исправлены:
  - пропадание Алсу;
  - «уплывание» поз между далёкими ключами;
  - выход камеры за край фона;
  - наложение героев;
  - неверная посадка на скамейку;
  - горшок, «прыгающий» между сценами;
  - лейка, остававшаяся в руке всю сцену;
  - застывшая концовка.
- **Lip sync.** Проверен покадрово на реплике Айдара `s1_01`:
  - губы смыкаются на м/б/п;
  - на А, О и У видны разные формы рта.
- **Озвучка.** Оценена по метрикам: ASR, F0, длительность. **На слух человеком не прослушана.** Произношение арабских фраз нужно прослушать заказчику и устазу.

## 3. Что не проверено / ограничения

- Анимация процедурная: ключи, генераторы шагов и пружины. Аниматор-человек её не правил. До уровня ручной покадровой анимации студии оно не дотягивает.
- Cloudflare R2 недоступен: ключ доступа имеет неверную длину (14 символов вместо 32), и загрузка падает. Поэтому видео выложено через приватный артефакт claude.ai: просмотр и скачивание идентичного MP4.
- Религиозные фразы ждут проверки устазом (`USTAZ_REVIEW.md`).
- На YouTube ничего не публиковалось.

## 5. Сведение (воспроизвести)

```bash
python episodes/ep01/render_ep.py VOICE_DIR video.mp4
python episodes/ep01/mix.py VOICE_DIR mix.wav
# двухпроходная нормализация: 1) loudnorm=I=-14:TP=-1.5:print_format=json → измеренные значения
# 2) loudnorm с measured_* + alimiter=limit=0.89, затем:
ffmpeg -i video.mp4 -i mix_norm.wav -c:v copy -c:a aac -b:a 192k -movflags +faststart sad_na_kryshe_ep01.mp4
python tools/qc_episode.py sad_na_kryshe_ep01.mp4 episodes/ep01/qc_ep01.json
```
