# Голоса и озвучивание: руководство

Статус: **методика**. Голоса не выбраны, синтез не запускался.

## 1. Проверенные технические факты (24.11.2026)

- Ключ ElevenLabs в окружении принимается API.
- Модели с русским языком (по ответу `/v1/models`): `eleven_v4`, `eleven_v4_turbo`, `eleven_v3`, `eleven_v3_conversational`, `eleven_multilingual_v2`, `eleven_flash_v2_5`, `eleven_turbo_v2_5`, `eleven_multilingual_sts_v2`.
- Баланс и тариф не проверены: у ключа нет права `user_read`. Перед тестами нужен ключ с этим правом или проверка в личном кабинете.

## 2. Принципы детской озвучки

Ориентиры; их уточнят измерения F0 и темпа речи в 30 сериях.

| Параметр | Ориентир |
|---|---|
| Темп речи детских персонажей | медленнее взрослого телевизионного; паузы между репликами, чтобы ребёнок успевал понять |
| Чёткость | полные окончания, без «проглатывания»; ударения по словарю |
| Эмоция | ярче, чем в жизни, но без крика; крик — только как редкий сюжетный акцент |
| Различимость | голоса героев отличаются по высоте, тембру и манере, чтобы ребёнок понимал, кто говорит, не глядя на экран |
| Возраст звучания | соответствует возрасту героя; взрослые — тёплые, спокойные, без «сюсюканья» |
| Громкость | ровная по серии; мастер −14…−16 LUFS, true peak ≤ −1 dBTP ⚠ |

## 3. Кастинг-тест (следующий этап, после утверждения персонажей)

1. Для каждого персонажа: бриф (возраст, характер, 3 эталонные реплики — нейтральная, радостная, расстроенная).
2. 3–5 кандидатов-голосов (Voice Design или библиотека ElevenLabs; при ограничениях на детские голоса — актрисы-травести).
3. Одинаковый тестовый текст на русском, включая арабские формулы (п. 4).
4. Слепое прослушивание: команда + 5–10 детей целевого возраста (с согласия родителей).
   - Критерии: понятность, симпатия, соответствие образу, отсутствие «роботизированности».
5. Фиксация: `voice_id`, модель, параметры stability/similarity/style, seed — для воспроизводимости.

## 5. Технический регламент файлов

- Каждая реплика — отдельный WAV 48 кГц / 24 бит, имя `S{сцена}_L{реплика}_{персонаж}_v{дубль}.wav`.
- Таймстемпы символов сохраняются рядом: `.align.json` для визем.
- Финальная сборка и громкость — FFmpeg (`PRODUCTION_TECHNOLOGY.md`, п. 6).
