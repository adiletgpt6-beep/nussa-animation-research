# Руководство по анимации (2D-пилот, совместимо с будущим 3D)

Статус: **стандарты производства**. Числовые ориентиры по монтажу и темпу будут откалиброваны по измерениям 30 серий Nussa (`research/data/episodes/*.metrics.json`), когда те будут получены.

## 1. Технические параметры

| Параметр | Значение |
|---|---|
| Разрешение | 1920×1080, 16:9 |
| FPS | 30 (CFR). Анимация персонажей в основном «по двойкам» (15 рисунков/с), быстрые действия и камера — «по единичкам» |
| Безопасная зона | титры и важные детали внутри 90% кадра |
| Цвет | sRGB / BT.709 |

## 2. Обязательный минимум «живости» в каждом кадре с персонажем

| Элемент | Норматив |
|---|---|
| Моргание | каждые 2–6 с, нерегулярно; длительность 4–6 кадров при 30 fps (закрытие 1–2, закрыто 1–2, открытие 2); дополнительное моргание при повороте головы |
| Взгляд | глаза начинают поворот на 2–4 кадра раньше головы |
| Дыхание | лёгкое движение груди и плеч в паузах; персонаж не замирает полностью дольше 1,5 с |
| Слушающий персонаж | реагирует (кивок, взгляд, моргание, мимика) минимум раз в 2–3 с реплики собеседника |
| Lip sync | виземы по таймингу речи; рот закрывается на «м/б/п»; «А» — максимальное открытие с движением челюсти |
| Акценты речи | на ударных словах — движение головы или бровей или жест (не на каждом слове) |
| Вторичное движение | волосы, одежда и головной убор запаздывают на 2–4 кадра и «досаживаются» после остановки |

## 3. Движение тела

| Действие | Норматив (30 fps) |
|---|---|
| Ходьба, обычный шаг | 14–16 кадров на шаг (≈ 1 шаг в 0,5 с); у детей шаг короче и чаще (12 кадров) |
| Бег | 8–10 кадров на шаг, фаза полёта, наклон корпуса вперёд |
| Контакт стопы | без проскальзывания: стопа на полу неподвижна в мировых координатах |
| Антиципация | перед каждым крупным действием (прыжок, бросок, вставание) — подготовительное движение в обратную сторону |
| Перекрытие (overlap) | части тела останавливаются не одновременно: корпус → голова → руки → волосы/одежда |
| Стрейч-сквош | в комедийных моментах и ударах; объём сохраняется |
| Арки | движения рук и головы — по дугам, не по прямым |

## 4. Камера и композиция

- Движения камеры — мотивированные (вслед за персонажем, раскрытие пространства), с плавным разгоном и торможением.
- Зум по плоской картинке без параллакса **запрещён** как основной приём.
- Правило третей и «воздух» по направлению взгляда.
- Крупный план для эмоции, средний для диалога, общий для ориентации в пространстве и физической комедии.
- Ориентиры длины плана будут взяты из измерений (ASL Nussa); предварительно 3–6 с, не больше 10 с без внутреннего движения.

## 5. Именование (общий стандарт 2D/3D)

- Кости: `root`, `spine_01..03`, `neck`, `head`, `upperarm_L/R`, `forearm_L/R`, `hand_L/R`, `thigh_L/R`, `shin_L/R`, `foot_L/R`, `ik_foot_L/R`, `ik_hand_L/R`, `hair_01..`, `cloth_01..`.
- Экшены: `<персонаж>__<действие>__<вариант>`, например `char__walk__happy`, `char__sit_down__default`.
- Виземы: `vis_A … vis_H, vis_X` (совместимо с Rhubarb); эмоции бровей: `brow_neutral|happy|sad|angry|surprised|worried`.

## 6. Контроль качества сцены (чек-лист аниматора)

- [ ] Нет кадров, где персонаж полностью неподвижен дольше 1,5 с (кроме намеренной паузы).
- [ ] Моргания расставлены и не синхронны у разных персонажей.
- [ ] Lip sync проверен покадрово на «м/б/п» и открытых гласных.
- [ ] Стопы не скользят.
- [ ] Предметы в руках не «плавают» (привязка child-of корректна).
- [ ] Силуэт действия читается.
- [ ] Цвет и свет сцены соответствуют color script.
