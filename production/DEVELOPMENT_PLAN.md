# План разработки оригинальных героев и производства первой 2D-серии

Статус: **план для утверждения заказчиком**.

На этом этапе ничего не утверждено:
- не выбраны название, герои и дизайн;
- сценарий не написан;
- производство не начато.

Каждый этап заканчивается контрольной точкой (**Gate**). Следующий этап стартует только после решения заказчика.

Основание — выводы исследования 15 серий Nussa: `research/FINAL_REPORT.md` и `production/RECOMMENDATIONS.md`. Мы берём принципы, но не копируем персонажей, сюжеты и стиль.

## 0. Неизменные требования (из ТЗ)

| Требование | Как проверяем |
|---|---|
| Оригинальный мусульманский сериал: свои герои, истории, стиль | Проверка на несходство с Nussa и другими сериалами на каждом Gate |
| Аудитория 4–12 лет, русская озвучка | Тест с детьми двух групп: 4–7 и 8–12 лет |
| Серия 4:00–6:00, 1920×1080, 30 fps | Автоматический QC (ffprobe) |
| Хук ≤ 5 с, без длинной заставки | Сценарий + аниматик: первая реплика или действие ≤ 5 с, титр ≤ 3–5 с |
| Без фоновой музыки, качественный звуковой дизайн | Чек-лист звука; в мастере нет музыкальной дорожки |
| Без изображения пророков, ангелов, шайтана | Чек-лист устаза на сценарии и аниматике |
| Религиозное содержание проверено устазом | Подпись в шапке сценария; CI-проверка поля `religious_review: approved` |
| Живая 2D-анимация: тело, глаза, руки, ноги, голова, мимика, lip sync | Приёмочные тесты технического прототипа (этап 5) |
| 3D — только после утверждения 2D-пилота | Gate 9 |

## 1. Концепция мира и семьи (1–2 недели)

**Результат:** 3 концепции на одну страницу каждая, на основе вариантов A/B/C из `PROJECT_BIBLE.md`. В каждой:
- состав семьи;
- место действия;
- источник конфликтов на сезон;
- 10 логлайнов серий;
- 3 рабочих варианта названия.

**Требования, вытекающие из исследования:**
- Ядро — дети разного возраста: младший и старший. Пара «младший ошибается и смешит — старший знает, но тоже ошибается» — основа почти всех проанализированных серий Nussa (наблюдение). То, что она работает на обе возрастные группы, — гипотеза для проверки тестом с детьми. Повторять их состав и роли буквально нельзя: подбираем свою конфигурацию, например трое детей или двоюродные братья и сёстры.
- Безмолвный персонаж-животное или иной «комический катализатор». У Nussa кот участвует в большинстве серий. Наш персонаж должен быть другим по виду, характеру и функции.
- Тёплые взрослые, которые ведут вопросами, а не нотациями. Решение о показе взрослых женщин (лицо, одежда) принимает устаз.
- Узнаваемый быт русскоязычного ребёнка: зима, квартира, школа, бабушка, двор, мечеть.

**Gate 1:** заказчик выбирает концепцию и название. Проверка на несходство.

## 2. Разработка героев (3–4 недели)

| Шаг | Результат |
|---|---|
| 2.1 Психологический профиль | Для каждого героя (4–6 основных): желание, страх, недостаток, сильная сторона, фирменная фраза, фирменный жест, роль в ансамбле, реакции «как злится / радуется / боится» |
| 2.2 Силуэты | 3–5 вариантов силуэта на героя. Тест: ансамбль узнаётся по чёрным силуэтам |
| 2.3 Эскизы | 3 варианта дизайна на героя в выбранном стиле |
| 2.4 Тест с детьми | 10–20 детей 4–12 лет (с согласия родителей): «кто тебе нравится, почему, кто смешной». Фиксируем результаты |
| 2.5 Model sheet | Турнараунд (4 вида), 12 эмоций, 10 поз, 9 визем, 10 кистей, цветовая карта. Требования — `CHARACTER_DESIGN.md` |
| 2.6 Проверки | Устаз: одежда и поведение. Психолог: эмоциональная безопасность. Сходство: Nussa и известные сериалы |

**Gate 2:** заказчик утверждает героев.

## 3. Голоса (1–2 недели, нужен бюджет)

1. Бриф голоса для каждого героя: возраст, тембр, темп, 3 эталонные реплики.
2. 3–5 кандидатов на героя через ElevenLabs Voice Design или библиотеку.
   - Сначала проверить правила платформы для детских голосов.
   - Альтернатива — актрисы, озвучивающие детей.
3. Слепое прослушивание: команда + дети.
4. Словарь произношения арабских формул (`VOICE_GUIDE.md`) утверждает устаз.

**Бюджет:** ориентир 30–60 тыс. символов на кастинг. ⚠ Сверить с тарифом. Тратить только после согласия заказчика.

**Gate 3:** заказчик утверждает голоса.

## 4. Сценарий пилота (2 недели)

Формат — `EPISODE_TEMPLATE.md`.

**Требования из исследования:**
- хук ≤ 5 с — действие и эмоция без слов;
- одна бытовая ситуация и одна ценность;
- ценность показана **поступком ребёнка** в кульминации;
- взрослый задаёт 1–2 вопроса;
- финальная шутка после развязки;
- одна бессловесная сцена 15–30 с;
- темп речи ≈ 50–70 слов/мин по всей серии;
- не больше 1–2 проверенных текстов-источников.

**Проверки:**
- устаз — все `[REL]`-маркеры;
- психолог — эмоциональная безопасность;
- хронометраж по таблице — 240–360 с.

**Gate 4:** заказчик утверждает сценарий.

## 5. Технический прототип анимации (2 недели) — ключевой этап качества

**Цель:** доказать, что конвейер даёт живую анимацию, а не «картинки с зумом».

**Результат:** тестовая сцена 15–20 с с двумя героями. Приёмочные тесты:

| Тест | Критерий приёмки |
|---|---|
| Ходьба и бег | Цикл без проскальзывания стоп; перекрытие движений; разные походки у разных героев |
| Поворот головы | 3/4 → профиль без «скачка», глаза опережают голову на 2–4 кадра |
| Моргание | Нерегулярное, 2–6 с, 4–6 кадров |
| Lip sync | По русской речи; рот закрывается на «м/б/п»; рассинхрон ≤ 2 кадров на контрольных словах |
| Мимика | 6 эмоций читаются без звука: тест с 5 детьми |
| Руки и предметы | Взять предмет, передать другому, предмет не «плавает» |
| Слушающий персонаж | Реагирует каждые 2–3 с: кивок, взгляд, моргание |
| Вторичное движение | Одежда и волосы запаздывают и «досаживаются» |
| Технический QC | 1920×1080, 30 fps CFR, громкость −14…−16 LUFS, true peak ≤ −1 dBTP |

**Инструменты:**
- Blender + Grease Pencil, гибрид cut-out-рига и рисованных вставок (`PRODUCTION_TECHNOLOGY.md`);
- lip sync по таймингам ElevenLabs + русский маппер «буква → визема»;
- Rhubarb — как резервный вариант.

Технологии, архитектура, автоматизация, сроки и бюджет прототипа и серий — [PRODUCTION_TECH_PLAN.md](PRODUCTION_TECH_PLAN.md) (по итогам VID-001). Там же предложение сделать прототип одной сцены 15–20 с в двух вариантах: 2D Grease Pencil и стилизованное 3D.

**Gate 5:** заказчик утверждает качество анимации. Если качество недостаточное — корректируем риг или технику до перехода к серии.

## 6. Озвучка пилота (1 неделя, бюджет)

- Реплики отдельными файлами, 2–4 дубля, таймстемпы символов.
- Тратим только в утверждённом бюджете.

## 7. Аниматик (1–2 недели)

- Раскадровка со звуком в реальном времени.
- Проверяем хук ≤ 5 с, темп, паузы, места для шуток.
- Повторная проверка устазом: нет запрещённых изображений.

**Gate 7:** заказчик утверждает аниматик.

## 8. Производство серии (4–8 недель, зависит от команды)

| Шаг | Результат |
|---|---|
| Ассеты | Риги героев (библиотека), 3–4 локации в 3D-пространстве, реквизит с точками захвата |
| Раскладка | Скрипт собирает сцены из сценария: персонажи, экшены, виземы, камеры |
| Анимация | Аниматор доводит ключевые позы, эмоции и комедийный тайминг |
| Звук | Фоли, атмосферы, акценты, «звуковые логотипы» героев; **без музыки** |
| Рендер и мастер | Blender → FFmpeg; автоматический QC |
| Тест с детьми | Досматривают ли сами, где теряют интерес, что повторяют после просмотра |

**Gate 8:** заказчик утверждает пилот.

## 9. Решение о 3D

Только после Gate 8. Используем заготовки из 2D:
- турнарауны;
- единые имена костей и экшенов;
- виземы как данные;
- 3D-окружения;
- color script.

## 10. Экономия без потери качества

| Решение | Экономия | Риск для качества и как его снять |
|---|---|---|
| Библиотека экшенов: ходьба, бег, сесть, встать, жесты, эмоции | Повторное использование в каждой серии | «Шаблонность» → аниматор вручную добавляет ключевые позы в каждой сцене |
| Окружения в 3D-пространстве, 3–5 стандартных камер на локацию | Раскладка серии за часы, а не дни | Однообразие → 1 новая локация на 2–3 серии |
| Скриптовая сборка сцены + lip sync из таймингов | Меньше рутинной анимации | Механичность → ручная доводка ключевых моментов |
| Безмолвный персонаж-животное | Не нужна озвучка, сильный юмор | — |
| Без фоновой музыки | Нет лицензий и композитора | Эмоцию держат пауза, крупный план, тишина и шумы — нужен хороший звукорежиссёр |
| Короткий фирменный титр вместо заставки | Нет отдельного ролика | — |
| ElevenLabs вместо студийной записи на кастинге и черновиках | Быстрые итерации | Детские голоса могут звучать неестественно → финал с актёрами при необходимости |
| Сезонный план локаций и героев | Ассеты переиспользуются в 10–13 сериях | Нужна дисциплина библии проекта |

## 11. Команда (минимум)

- Режиссёр-постановщик.
- Сценарист.
- Художник персонажей и фонов.
- Аниматор-риггер (Blender).
- 1–2 аниматора.
- Звукорежиссёр.
- Технический специалист (Python/конвейер).
- Консультанты: устаз, детский психолог.

Без опытного аниматора-постановщика добиться «живой» анимации нельзя: автоматизация даёт черновую сцену, а не актёрскую игру.

## 12. Решения, которые нужны от заказчика сейчас

1. Утвердить исследование (этот этап) и перейти к Gate 1.
2. Назначить устаза-консультанта и детского психолога.
3. Бюджет:
   - ElevenLabs — кастинг и пилот;
   - GPU-рендер или рабочая станция;
   - команда (штат или фриланс).
4. Политика показа взрослых женщин и детей разного пола — решает устаз.
5. Допустим ли вокальный нашид в отдельных сценах, или полная тишина без музыки — решает устаз.
