# Инструкции для агентов

- Язык документов — русский. Аудитория сериала — 4–12 лет, серия строго 4–6 мин, 1920×1080, 30 fps.
- **Не выдумывать** просмотренные кадры, субтитры, диалоги, статистику, результаты. Каждое утверждение о сериях Nussa должно опираться на `research/data/episodes/*.metrics.json` или на расшифрованные материалы; иначе — пометка «гипотеза» / «не проверено».
- В репозиторий не коммитить: видео, аудио, кадры, полные транскрипты чужих серий, ключи (`*.key`, age identity), `.env`. Приватные материалы — только зашифрованными (`research/data/private/*.age`).
- Религиозные утверждения — со ссылкой на источник и статусом «требует проверки устазом», пока устаз не утвердил.
- Не тратить платные кредиты (ElevenLabs и др.) и не запускать платные облачные вычисления без согласования бюджета.
- Не утверждать название, персонажей и сценарий без решения заказчика.
- После каждого этапа обновлять `STATUS.md` и `HANDOFF.md`.
- Конвейер: `research/pipeline/` (см. README там). Идентификаторы серий NS-001…NS-030 = ранг по просмотрам на дату сбора.
