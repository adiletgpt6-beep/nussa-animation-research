# Исследование Nussa → собственный мусульманский детский мультсериал

Цель — изучить, почему популярен сериал Nussa (YouTube: NussaOfficial), и на этой основе подготовить
фундамент для **собственного** оригинального русскоязычного мультсериала (4–12 лет, 4–6 мин,
1920×1080, 30 fps; пилот в 2D, затем 3D). Мы ничего не копируем.
