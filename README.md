# Исследование Nussa → собственный мусульманский детский мультсериал

Цель — понять, как устроены самые популярные серии **Nussa** (YouTube: NussaOfficial), и на этой основе подготовить фундамент **собственного** оригинального русскоязычного мультсериала:
- аудитория 4–12 лет;
- серия 4–6 мин;
- 1920×1080, 30 fps;
- пилот в 2D, затем 3D.

Мы ничего не копируем.

**Статус (2026-11-25):** исследование 15 серий завершено; технический разбор видео VID-001 завершён; подготовлены концепции сериала и план автоматизированного производства (ждут решения заказчика); производство не начато. См. [STATUS.md](STATUS.md).
